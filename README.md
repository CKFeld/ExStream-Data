# ExStream-Data
ExStream data from 15 experiments subjected to Bayesian Meta-Analysis by Feld et al. (submitted)

This is the data available for review with the manuscript “Stream macroinvertebrate responses to agricultural stressors: a meta-analysis of standardised mesocosm experiments across four continents” submitted to Global Change Biology by Feld, Palt, et al.

<<Feld_Palt_etal_Metrics_perChannel.csv>> contains the macroinvertebrate metrics
calculated for each experimental channel.

<<Feld_Palt_etal_EffectSizes_perStudyTreatmentMetric.csv>> contains effect sizes calculated for 
each treatment and metric combination and for each experiment.

<<Feld_Palt_etal_MetricHeterogenity_perTreatmentMetric.csv>> contains the heterogeneity metrics 
of effect sizes for each treatment - metric combination.

<<Feld_Palt_etal_PosteriorEffects_perTreatmentMetric.csv>> contains posterior effects derived from 
the Bayesian meta-analyses for each treatment - metric combination.

<<Feld_Palt_etal_BayesFactors_perTreatmentMetric.csv>> contains Bayes Factors (BF) of all 
prior comparisons (H10, H20, H30) for each treatment - metric combination.
